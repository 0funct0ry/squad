title: squad docs
description: Documentation for squad, a single-binary, web-based SQLite client.
---

squad is a self-contained command-line tool that opens a SQLite database and
serves a modern web UI for exploring, querying, editing, and exporting it.
The entire application ships as a single statically linked binary with the
web UI embedded.

Start with [Installation](/squad/docs/getting-started/installation/) or jump
straight to the [CLI Reference](/squad/docs/cli-reference/global-flags/).
